Triforce Recompiled - The Legend of Zelda: Tri Force Heroes on PC
==================================================================
https://github.com/Tillundmausi/Triforce-Recompiled

Unofficial fan project, not affiliated with or endorsed by Nintendo.
No game files are included - you need your own copy of the game.

START
  1. Start TriforceRecompiled.exe
  2. The "Setup" tab explains every step (decrypting your game with GodMode9,
     choosing the file, installing it).
  3. Press PLAY.

REQUIREMENTS
  - Windows 10/11 64-bit, graphics card with Vulkan support
  - Your own decrypted Tri Force Heroes (.cia or .3ds)
    Tested: European version (CTR-P-EA3P) without update
  - Online co-op (optional): Steam running and signed in
  - Discord status (optional): Discord desktop app running

DEFAULT CONTROLS (change them in Settings > Controls)
  Move           W A S D          Walk slowly   Left Shift
  A / B / X / Y  K / J / I / U    L / R         Q / E
  ZL / ZR        1 / 3            D-Pad         arrow keys
  Start/Select   Enter / Backspace
  Touch screen   mouse            Launcher      Esc
  F9 swap screens, F10 next layout, F11 fullscreen

YOUR FILES
  Saves, settings, logs and crash reports are kept in the "user" folder next to
  the exe. Copy that folder to keep your progress when updating.

PROBLEMS?
  Open an issue on GitHub and attach user\log\azahar_log.txt
  (and user\crash.txt if the game crashed).
